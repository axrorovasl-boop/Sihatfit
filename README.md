# ТРЕНЕР ИИ — обуна билан ишлайдиган сайт

Бу папкада тайёр сайт бор: `index.html` (бутун ilova), `schema.sql` (Supabase учун база тайёрлаш скрипти).

Қуйидаги қадамларни кетма-кет бажар. Ҳаммаси бепул, картасиз.

## 1. Supabase (логин + база)

1. **supabase.com** → **Start your project** → GitHub/email билан рўйхатдан ўт
2. **New project** → ном бер (масалан `trener-ii`) → парол ўрнат (эсда сақла) → регион: Europe (яқинроқ бирини танла) → **Create new project** (1-2 дақиқа кутади)
3. Чап менюда **SQL Editor** → **New query**
4. Шу папкадаги **`schema.sql`** файлининг ҳаммасини очиб, ичидаги ИККИТА жойдаги `ADMIN_EMAIL` сўзини ўзинг логин қиладиган ҳақиқий email'ингга алмаштир (масалан `karim@gmail.com`)
5. Тайёр матнни SQL Editor'га копия қил, **Run** бос — "Success" деб чиқиши керак
6. Чап менюда **Settings → API** — у ердан **Project URL** ва **anon public** калитини нусхала (сақлаб қўй, кейин керак бўлади)

## 2. index.html'ни созлаш

`index.html` файлини (масалан Notepad'да) оч, боши томонда қидир (Ctrl+F): **`PASTE_YOUR_`**

Уч жойни топасан:
```
var SUPABASE_URL = "PASTE_YOUR_SUPABASE_URL_HERE";
var SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY_HERE";
var ADMIN_EMAIL = "PASTE_YOUR_ADMIN_EMAIL_HERE";
```
Уларни 1-қадамда олган қийматларга алмаштир (ADMIN_EMAIL — schema.sql'га ёзган email билан **бир хил** бўлиши шарт). Сақла.

## 3. GitHub'га юклаш (дастур ёзиш шарт эмас)

1. **github.com** → рўйхатдан ўт (агар йўқ бўлса)
2. **New repository** → ном бер (масалан `trener-ii`) → **Create repository**
3. Очилган саҳифада **"uploading an existing file"** деган ҳаволани бос
4. `index.html` ва `schema.sql` файлларини шу ерга судраб ташла (drag & drop)
5. Пастда **Commit changes** бос

## 4. Vercel'га жойлаштириш (сайтни жонли қилиш)

1. **vercel.com** → **Continue with GitHub** орқали кир
2. **Add New → Project**
3. 3-қадамда яратган `trener-ii` репозиторийни танла → **Import**
4. Ҳеч нарсани ўзгартирма, **Deploy** бос — 30 сония кутасан
5. Тайёр! Сенга `https://trener-ii-xxxx.vercel.app` кўринишида ҳақиқий ссылка беради — шу линк ҳамма учун ишлайдиган сайтинг

## 5. Текшириш

1. Ўз ссылкангни оч, ADMIN_EMAIL'га ёзган email'ингни кирит, "Отправить ссылку" бос
2. Почтангга Supabase'дан хат келади — ичидаги ссылкани **шу қурилмада** оч
3. Автоматик киритилиб, дарров дастур очилиши керак (сен админ бўлганинг учун рухсат сўраш шарт эмас)
4. Юқорида **"Админ"** таб пайдо бўлганини кўр — шу ердан бошқаларга email орқали 1/3/6/12 ойлик рухсат бера оласан

## Бошқаларга рухсат бериш

Ким сендан рухсат сўраса — унинг email'ини **Админ** табига ёзиб, муддатни танлаб, "Дать доступ" бос. У киши ўша email билан сайтга кириб, ўз (бошқалардан алоҳида, хавфсиз) маълумотини кўради ва ёзади.

## iPhone / Android'га ўрнатиш

Сайт энди **PWA** (веб-илова) сифатида ишлайди — App Store/Play Market'сиз ҳам телефон экранига "иложа" қилиб қўйилади:

- **iPhone (Safari)**: сайтни оч → пастдаги улашиш (share) тугмаси → **"На экран «Домой»"** → энди бошқа иловалар қатори иконка билан очилади
- **Android (Chrome)**: сайтни оч → ўнг юқори **⋮** менюси → **"Установить приложение"** (ёки браузер ўзи пастdan таклиф қилади) → бир хил иловадек ишлайди, ўз иконкаси билан

3-4-қадамда (GitHub/Vercel) `icon.svg`, `manifest.json`, `sw.js` файлларини ҳам бошқалари билан бирга юклашни унутма — уларсиз иконка ва "ўрнатиш" таклифи ишламайди.

## Ҳар машқ учун ўз видеонгни юклаш

Энди залга бориб ҳар бир машқ учун телефонда видео олсанг, шуни сайтга юклаш мумкин:

1. Админ email билан киргансан (сен) → исталган машқда **"Техника ▸"** тугмасини бос
2. Очилган ойнача пастида **"📹 Загрузить своё видео"** тугмаси кўринади (фақат сенга, админга кўринади)
3. Телефондаги видеони танлайсан → автоматик юкланади → шу заҳоти ўша ойнача ичида кўринади
4. Шундан кейин **ҳар бир фойдаланувчи** ўша машқни очганда — сенинг ҳақиқий видеонгни кўради (пиктограмма ўрнида)

Агар олдин `schema.sql`'ни бир марта ишга туширган бўлсанг — **янгиланган (тўлиқ) версиясини яна бир марта** Supabase SQL Editor'да ишга тушир (хавфсиз, эски маълумотга тегмайди) — видео жадвали ва сақлаш жойи (Storage) шу орқали яратилади.

## Эслатма

- Ҳар кимнинг тренировка маълумоти энди **булутда** (Supabase базасида) сақланади — браузер тозаланиб қолса ҳам йўқолмайди
- Google Calendar эслатмалари ва ChatGPT/Claude'га очиш тугмалари — олдингидек ишлайверади (буларга Supabase керак эмас)
- Кейинги қадам сифатида: тўлиқ ўзинг яратадиган (кутубхонада йўқ) машқ + унга видео/расм ссылкаси қўшиш имконини хоҳласанг — айт, шуни ҳам қўшиб бераман
